## ২. প্রজেক্ট ওভারভিউ (যা পাওয়া গেছে)

- **Stack:** Next.js 16.3.5 · React 19.2 · Prisma 6.19.3 · PostgreSQL · Tailwind 4 · Vercel
- **পেজ:** 21টা রুট (`app/`) — হোম, ক্যাটাগরি, সার্ভিস তালিকা+বিস্তারিত, সার্চ, এলাকা, auth, প্রোফাইল, অ্যাডমিন, ওনার, কমিউনিটি পেজ (donors/advisory/partners), notices, contact, about, privacy, more-services
- **API:** 17টা রুট — auth (4), services CRUD+claim, directory search, locations, owner, admin (services approve/reject, users, claims)
- **ডেটা:** 21 ক্যাটাগরি (~100 সাব-ক্যাটাগরি), 44 static লিস্টিং (25 verified + 19 demo), 88 EIIN প্রতিষ্ঠান (satkania.ts), 64 জেলা, 472KB লোকেশন JSON
- **দুই মোড:** `DATABASE_URL` না থাকলে static fallback; থাকলে Prisma — ফলব্যাক ডিজাইনটা বুদ্ধিমানের কাজ 👍

### ✅ যা ভালো আছে (Strengths)
1. **পরিষ্কার দ্বি-মোড আর্কিটেকচার** — DB ছাড়াই সাইট চলে, প্রতিটা API-তে try/catch fallback।
2. **এলাকা ট্যাগ নিয়ম** (`কাঞ্চনা` / `সাতকানিয়া পৌরসভা` / `আমিলাইশ-কাঞ্চনা` / `সাতকানিয়া (উপজেলা)`) — ডেটা মিশ্রণ রোধে চমৎকার চিন্তা।
3. **Auth ফাউন্ডেশন সঠিক:** scrypt পাসওয়ার্ড হ্যাশ, SHA-256 সেশন টোকেন, httpOnly + SameSite=Lax cookie, login/register-এ rate limit।
4. **XSS নিরাপদ:** `dangerouslySetInnerHTML` কোথাও নেই; React default escaping।
5. **রেপোতে কোনো সিক্রেট নেই** — `.env*` gitignore-এ, শুধু `.env.example`।
6. **Schema ডিজাইন ভবিষ্যতমুখী** — CategoryField/ServiceFieldValue (EAV), Claim/Review/Report/Favorite, 4-স্তর লোকেশন।
7. **Lazy Prisma Proxy** (`lib/prisma.ts`) — DB ছাড়া বিল্ড ভাঙে না।
8. **বাংলা-ফার্স্ট UX** — priyosherpur-এর সাথে UI প্যারিটি (slider, ticker, union grid, bottom nav, side menu) ভালোভাবে ধরা হয়েছে।
9. **Union তালিকা যাচাইকৃত** — 17 ইউনিয়ন Wikipedia-এর সাথে মিলেছে (নিচে §৬ দেখুন)।

## ৩. 🔴 P0 — Critical (DB মোড চালুর আগে অবশ্যই ঠিক করতে হবে)

### P0-1. TypeScript এরর — প্রোডাকশন বিল্ড ভাঙবে
- **ফাইল:** `app/api/admin/claims/[id]/route.ts:9` — `tx` প্যারামিটারে implicit `any` (TS7006)।
- **প্রমাণ:** `npx tsc --noEmit` ফেল করে। Next.js বিল্ডে type-check চলে, তাই Vercel ডিপ্লয় ফেল হবে।
- **ফিক্স:** `tx: Prisma.TransactionClient` টাইপ যোগ করা (৫ মিনিটের কাজ)।

### P0-2. DB মোডে লিস্টিং সাবমিশন 100% ফেল হবে (FK ভাঙন)
- **চেইন:** `prisma/seed.ts` কোনো **Category/District রো সিড করে না**, অথচ `app/add-listing/page.tsx` static string id পাঠায় (`categoryId: "doctor"`, `districtId: "chattogram"`) — DB-তে id হলো cuid।
- **ফল:** `POST /api/services` → Prisma FK violation → বিভ্রান্তিকর `503 DATABASE_NOT_CONFIGURED`।
- **বোনাস বাগ:** `upazilaId: upazila || "pending"` — আক্ষরিক `"pending"` স্ট্রিং FK হিসেবে যায়।
- **ফিক্স:** (a) seed-এ 21 ক্যাটাগরি + লোকেশন সিড করা; (b) add-listing-এ DB category/district id ব্যবহার করা (API থেকে লোড); (c) `"pending"` হ্যাক সরিয়ে proper validation।

### P0-3. প্রথম Admin বানানো অসম্ভব (ডেডলক)
- `register` সবসময় `role: "USER"` সেট করে; প্রমোশনের একমাত্র পথ `PATCH /api/admin/users` — যেটা নিজেই admin চায়। Seed-এ কোনো admin নেই, কোনো promote স্ক্রিপ্টও নেই।
- **ফিক্স:** seed স্ক্রিপ্টে env-var থেকে admin বানানো (`ADMIN_PHONE`/`ADMIN_PASSWORD`) বা একবারের CLI (`npm run db:promote -- <phone>`)।

### P0-4. Home/Categories থেকে সার্চ ভাঙা (`?q=` উপেক্ষিত)
- `/` ও `/categories`-এর ফর্ম GET করে `/search?q=...`, কিন্তু `app/search/page.tsx` client-only state (`useState("")`) — URL param পড়ে না। ফলে query হারিয়ে যায়, সবসময় "সব ফলাফল" দেখায়।
- **ফিক্স:** `useSearchParams()` দিয়ে `q` init + auto-search।

### P0-5. DB-তে approve করা লিস্টিং কোথাও দেখা যায় না / 404
- `/services` ও `/services/[id]` **শুধু static `data/services.ts` পড়ে** — DB পড়ে না।
- `/search` (API দিয়ে) DB ফলাফল দেখায়, কিন্তু প্রতিটা রেজাল্ট লিংক করে `/services/<cuid>` → static lookup ফেল → **404**।
- **ফল:** Full মোডে approve করা প্রতিটা লিস্টিং 404-এ মরে।
- **ফিক্স:** services তালিকা+বিস্তারিত পেজে DB-first + static-fallback লজিক (API রুট যেমন করে)।

### P0-6. Claims রিভিউ করার UI নেই
- `ClaimButton` কম্পোনেন্ট কোথাও ব্যবহার হয় না; detail পেজে claim বাটন নেই; Admin পেজে শুধু PENDING services — claims/users ট্যাব নেই। API আছে, UI নেই = ফ্লো অচল।
- **ফিক্স:** detail পেজে ClaimButton বসানো + admin-এ Claims/Users সেকশন।

### P0-7. "আমার জমা" তালিকা নেই
- Owner API শুধু `claimedById` দেখায়; `createdById` (submitter) দেখায় না। জমা দেওয়ার পর user PENDING স্ট্যাটাস ট্র্যাক করতে পারে না।
- **ফিক্স:** `/api/owner/services` (বা নতুন `/api/me/services`)-এ `createdById` যোগ + UI।

- `next/link` কোথাও নেই — সব `<a href>` = প্রতিটা নেভিগেশনে full reload। P2।
- `loading.tsx` / `error.tsx` / `not-found.tsx` নেই — DB এরর/404-এ কাঁচা Next পেজ। P2।
- Seed ~5000 sequential upsert — ধীর, timeout ঝুঁকি; batch/`createMany`+`skipDuplicates`। P2।
- `take: 50/100` কিন্তু pagination নেই; name সার্চে pg_trgm index নেই। P2।
- BottomNav `active` অনেক পেজে সেট নেই (detail/contact ইত্যাদিতে "হোম" জ্বলে)। P3।
- `services/page.tsx` সাব-টাইলে "N টি" — অন্য জায়গায় "N টি তথ্য"; ছোট inconsistency। P3।

**ডেড কোড / অব্যবহৃত অ্যাসেট (পরিষ্কার করুন)**
- `data/locations.ts`, `data/location-master.ts` — কোথাও import হয় না।
- `satkaniaInstitutes` (88 EIIN!) — কোথাও ব্যবহার হয় না। এটা সম্পদ — education/area পেজে তারে বাঁধুন।
- `Category.count` ফিল্ড — UI আসল `countByCategory()` ব্যবহার করে; hardcoded count মিথ্যা/বাসি।
- `Review`/`Report`/`Favorite`/`ServicePhoto` মডেল — API/UI শূন্য। হয় রোডম্যাপে রাখুন, নয় স্কিমা ছোট করুন।
- ডুপ্লিকেট সার্চ লজিক: `/api/services` GET ≈ `/api/directory/search` GET — একীভূত করুন।

**Auth/সেশন হার্ডেনিং**
- Expired session cleanup job নেই — টেবিল বাড়তেই থাকবে। P2।
- Login-এ session rotation নেই; `me`/`logout` stale cookie + no-DB-তে 500 দেয় (try/catch নেই)। P3।
- `verifyPassword` malformed hash-এ `timingSafeEqual` throw করতে পারে → 500 বদলে 401 হওয়া উচিত। P3।
- Claim approve-এ role `BUSINESS_OWNER`-এ প্রমোট হয় না (owner শনাক্তকরণ `claimedById` দিয়ে চলে — অসামঞ্জস্য)। P2।
- API এরর মাস্কিং: `POST /api/services` FK/validation সব ধরে `503 DATABASE_NOT_CONFIGURED` বলে — ডিবাগ কঠিন। P2।
- Slug `Date.now()` — একই মিলিসেকেন্ডে collision সম্ভব (কম ঝুঁকি); `cuid`/random suffix ভালো। P3।
- Cookie নাম `localhub_session` — ব্র্যান্ডের সাথে অমিল (কার্যকারিতায় সমস্যা নেই)। P3।

**A11y**
- Drawer-এ Esc-এ বন্ধ / focus trap নেই; slider auto-play-এ pause নেই; emoji icon-এ `aria-hidden` নেই। P2/P3।

**বিল্ড/কনফিগ**
- `tsconfig`: `noUnusedLocals`/`noUncheckedIndexedAccess` চালু করলে ডেড কোড ধরা পড়বে। P3।
- Prisma 7-এ `package.json#prisma` config deprecated — `prisma.config.ts`-এ মাইগ্রেট করার নোট রাখুন। P3।
- এই sandbox-এ `prisma generate` engine ডাউনলোড ব্লকড ছিল (নেটওয়ার্ক সীমা) — Vercel/CI-তে চলার কথা; তবু বিল্ড engine-download-নির্ভর, এটা মনে রাখুন। P3।
